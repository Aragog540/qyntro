# ⚡ DataFlow Frontend (Qyntro)

This directory contains the React 19 + Vite frontend application for **DataFlow**.

For full project documentation, architecture, backend setup, and feature guide, please refer to the main [Root README.md](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run Oxlint
npm run lint
```

## Tech Stack

* **React 19** with Vite 8
* **ReactFlow** (`reactflow`) for visual graph canvas
* **Zustand** for state management
* **Tailwind CSS v4** & custom CSS theme variables
* **PapaParse** for client-side CSV processing
* **Plotly.js** & **Recharts** for interactive visual analytics
* **@tanstack/react-virtual** for virtualized high-volume data tables
